
# YOLOv8 + AMCA for Underwater Waste Detection

## Project
Underwater waste detection using YOLOv8 and a proposed
Adaptive Momentum with Cosine Annealing (AMCA) optimizer.

## Dataset
MarineWaste-18K, stored separately in Google Drive.

## Project Files
- `amca.py` — AMCA optimizer implementation
- `train.py` — preliminary YOLOv8 baseline training script
- `configs/` — configuration files

## Training Environment
Google Colab GPU with PyTorch and Ultralytics.

## Important
Dataset paths and AMCA integration must be verified before
running the final experiments.
